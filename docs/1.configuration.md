The provider needs a default Stripe account and a signing secret for its webhook endpoint. Keep the credentials in the environment. The configuration files hold placeholders only.

## Configure the published module

Install the provider with `ajs project modules add @antelopejs/stripe` and `ajs project modules install`. Each consumer module declares the payment or subscriptions interfaces that it imports. The following configuration uses the published Stripe provider and reads the credentials from environment overrides.

```typescript [antelope.config.ts] docs-check
import { defineConfig } from "@antelopejs/interface-core/config";

export default defineConfig({
  name: "my-project",
  modules: {
    stripe: {
      source: {
        type: "package",
        package: "@antelopejs/stripe",
        version: "^1.1.0",
      },
      config: {
        apiKey: "REPLACE_VIA_ENV",
        webhookSecret: "REPLACE_VIA_ENV",
        endpoint: "stripe",
        maxNetworkRetries: 2,
        accounts: {
          europe: {
            apiKey: "REPLACE_VIA_ENV",
            webhookSecret: "REPLACE_VIA_ENV",
          },
        },
      },
    },
  },
  envOverrides: {
    STRIPE_SECRET_KEY: "modules.stripe.config.apiKey",
    STRIPE_WEBHOOK_SECRET: "modules.stripe.config.webhookSecret",
    STRIPE_EU_SECRET_KEY: "modules.stripe.config.accounts.europe.apiKey",
    STRIPE_EU_WEBHOOK_SECRET:
      "modules.stripe.config.accounts.europe.webhookSecret",
  },
});
```

Before startup, supply the four environment variables through your local secret manager or your deployment environment. Use the signing secret of each endpoint. The API key and the secret of another Stripe endpoint do not verify its deliveries. If you only need the default account, remove the `europe` account and its overrides.

To develop the provider, build a local checkout and replace the package source with `{ type: "local", path: "../stripe" }`. The CLI writes placeholder credentials, so environment overrides must replace them before startup.

## Configuration keys

| Key             | Meaning                                                                                                    |
| --------------- | ---------------------------------------------------------------------------------------------------------- |
| `apiKey`        | Secret API key for the default account.                                                                    |
| `webhookSecret` | Signing secret for the default account's endpoint.                                                         |
| `endpoint`      | Path of the built-in route, default `stripe` (`POST /stripe`). It does not mount a portable webhook route. |
| `accounts`      | More named accounts, each with `apiKey` and `webhookSecret`.                                               |
| Other keys      | Stripe SDK options that every account shares, such as `apiVersion`, `maxNetworkRetries`, and `timeout`.    |

The trailing `provider` argument of the payment and subscription calls selects an account by name, such as `"europe"`. Omit it to use the top-level default account. Pass the same selector to creation, reads, mutations, and webhook verification, because one account cannot read the IDs of another. An unknown selector rejects the call. It does not fall back to the default account.

The selector picks a configured Stripe account. It does not pick a provider implementation, and it does not set a Stripe Connect account header. The Stripe-specific `GetClient()` and the built-in route always use the default account.

## Optional integrations

- A module that implements `@antelopejs/interface-api` mounts the [built-in webhook route](./5.legacy-stripe.md). Without it, the provider logs a warning and starts anyway. Portable consumers mount their own route and call `VerifyWebhook` in both cases.
- A module that implements `@antelopejs/interface-redis` relays PaymentIntent changes to the Stripe-specific watchers of the other instances. Without it, watchers receive only the deliveries that reach the built-in route of their own instance. Portable webhook processing does not need Redis.

The [README compatibility table](../README.md#compatibility) lists the interface ranges from `package.json`. This configuration sets up Stripe only. It does not configure any other payment provider.
